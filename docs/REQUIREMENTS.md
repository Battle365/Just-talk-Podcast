# MVP Requirements

- Multiple hosts joining from separate phones.
- Dedicated guest room and host controls.
- Multi-participant screen layout.
- White studio treatment with Just Talk Podcast branding.
- On-screen participant introductions/lower thirds.
- Private preparation library.
- AI-assisted topic prompts and questions.
- Maximum episode duration: 45 minutes.
- Configurable licensed intro audio; development uses a placeholder.
- Raw recording retained separately from automatically edited output.
- Video upload slot.
- YouTube live/publishing workflow.
- Finished-episode Spotify publishing path.
- Fade to black at episode end.
- Twice-monthly show scheduling support.
- Automatic analytics ingestion where provider APIs permit.
- Architecture leaves service boundaries for scaling without complicating the host UI.
